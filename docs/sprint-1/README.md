# Wayback Public Library – Sprint 1

This directory contains the documentation and other supporting models developed and or revised during Sprint 1 of the Wayback Public Library project.

## Sprint Goal

Develop a consistent data model for the library system and implement basic functionality for adding library items and recording checkouts. 

## Requirements

The `requirements` directory contains:

- Revised Sprint 1 user stories and acceptance criteria
- Requirements carried forward from Sprint 0
- Client clarifications relevant to the selected functionality

The primary focus is identifying patrons and library items, recording checkouts, and adding items to the library's collection.

## Models

The `models` directory will contain the supporting models developed or revised for Sprint 1, including:

- Updated ERD
- Relational database model
- Checkout activity diagram
- Add library item activity diagram
- Checkout wireframe
- Add library item wireframe

The models will be reviewed against the selected user stories and used to guide implementation.

## Development

Sprint 1 development will build on the PHP proof of concept established during Sprint 0.

The team will review existing database implementations, agree on the best fitting database structure, and integrate the selected functionality into the current website.

## Testing

The team will test implemented functionality against the acceptance criteria for each selected user story.

Testing will include verifying database changes, checking valid and invalid inputs, and confirming that the integrated functionality behaves as expected.

If it does not behave as expected, the issues will either require updates on the model and or propose fixes to be developed.

## Task Management

Sprint 1 tasks are tracked through the Wayback Public Library GitHub Projects board.

The board includes some work carried forward from Sprint 0 and separates completed work by sprint.
