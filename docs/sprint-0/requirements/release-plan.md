# WPL Initial Release Plan

This release plan provides the initial development order for the Wayback
Public Library system based on the requirements analysis completed during
Sprint 0 and current client priorities.

The plan may be adjusted as requirements are clarified.

## Sprint 0 - Project Foundation and Proof of Concept

Planned work includes:

- Establish the team's development environment and project resources.
- Complete the initial requirements analysis.
- Create and prioritize the initial product backlog.
- Develop the required proof of concept.
- Demonstrate a database relationship between Patron, Checkout, and
  Item Copy.
- Read and display data from the proof-of-concept database.
- Collect user input and store it in the database.
- Prepare initial models needed to support development.

This is an initial release plan rather than a fixed commitment. User story
priorities and sprint assignments may change as requirements are clarified,
development effort becomes better understood, and client feedback is
received.
